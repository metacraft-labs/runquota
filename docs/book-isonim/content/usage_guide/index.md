# Usage guide

- [Running the daemon](/usage_guide/daemon) — `runquotad`: configuring the
  budget, what it prints at startup, and how it shuts down.
- [The `runquota` CLI](/usage_guide/cli) — inspecting the daemon and running a
  command under a lease.
- [Reading the history](/usage_guide/stats) — `runquota stats`: what has been
  recorded, what is slow, and the raw rows.
- [The observation store](/usage_guide/observations) — what is recorded, where
  it lives, who may read it, and how long it is kept.
